# AI時間割 (School Timetable AI)

学校のクラス・先生・科目・教室のデータから、条件（先生の授業不可時間、科目の1日最大回数など）を
守りながら時間割を自動生成（駒入れ）し、画面上のグリッドでドラッグ操作・確定・駒はずしなどにより
手直し・調整できるWebアプリです。

## 使い方の流れ

0. **サンプルデータ**: 「基本設定」画面の「サンプルデータを使ってみる」、またはヘッダーのフラスコアイコンから、
   中学校3学年×5クラス（15クラス）・先生約25人分のクラス・先生・科目・教室・授業・会議を含むモックデータを
   読み込んで、すぐに操作感を試せます。各クラスの週コマ数は実際の中学校の標準授業時数に近い構成（主要5教科
   4コマ・保健体育3コマ・技術家庭2コマ・音楽/美術/道徳/学級活動各1コマ）で週29コマとしており、5日制×6時限＝
   週30コマ枠のほぼ全て（97%）を使用します。教員を複数クラスで共有する現実的な構成のため、「AIで自動駒入れ」
   一回で全コマが埋まりきらないこともありますが、その場合は「タイル表示」の残り駒や「AI提案」を使った手直し、
   または再度の自動駒入れ（ランダム性があるため結果が変わることがあります）で調整できます。
1. **基本設定**: 学校名、週の日数、1日の時限数、昼休みの位置を設定。「曜日ごとの時限数」で特定の曜日だけ
   時限数を変更できます（既定で月曜のみ5時限＝6限なし）。存在しない時限は時間割上でグレー表示され、
   駒入れ・個別条件・会議設定・タイル表示など全ての画面で自動的に除外されます。
2. **マスタデータ**: クラス・先生・科目・教室を登録。科目・教室は「プリセットから追加」で、国語・数学・理科…
   といったよく使う名称をチェックボックスで選んで一括登録できます。クラスも「クラスを一括生成」で学年数・
   組数を指定すれば「1年1組」～のような名称をまとめて作成できます（一つずつ入力する必要はありません）。
3. **授業設定**: クラス×科目×先生×教室の組み合わせ（授業）を、週コマ数・連続授業の有無とともに登録
4. **個別条件**: 先生・クラス・科目・教室ごとに授業できない曜日・時限（禁制）を設定できるほか、
   「全体オプション」タブで駒入れの動作条件（同じ科目を連続時限に置かない、曜日ごとに均等分散させる、
   試行回数など）をプリセットとして複数保存し、切り替えられます。試行回数は「AIで自動駒入れ」を実行する際の
   実際の試行上限で、多く設定するほど残り駒0に近づきやすくなりますが、その分時間がかかります（最大200回）。
5. **時間割作成**: 選択中の全体オプションを使って「AIで自動駒入れ」ボタンで自動配置。試行回数は画面右上の欄で
   直接指定できます（個別条件画面の全体オプションにも反映されます）。授業設定画面で「先入れ」に星を付けた授業は、
   入りにくい選択授業などとして他より先に配置されます。グリッド上でドラッグ&ドロップにより駒を移動・入れ替え
   でき、ドラッグ中は移動・入れ替えても競合しないマスが緑色でハイライトされます。右クリックメニューで確定/
   確定解除・駒はずしが可能。「AI提案を見る」からは、その駒を移動・入れ替えできる候補をAIが提示し、クリックで
   適用できます（未配置の授業側にも同様の提案ボタンがあります）。駒の変更はツールバーの「一手戻し」「やり直し」
   （Ctrl+Z / Ctrl+Shift+Z）でいつでも取り消せます。未配置の授業は「残り駒」パネルに表示されます。
6. **タイル表示**: 「全クラス一覧」タブでは、すべてのクラス・学年の時間割（科目・先生入り）を学年ごとにまとめて
   並べて確認できます。「一括表」タブでは、縦に学年・クラス、横に曜日・時限を並べた一つの表（すべて正方形の
   マス）で全学年・全クラスのコマをまとめて確認できます。空きコマがあれば赤いセルとエラー表示（該当クラス・
   曜日・時限の一覧）で示され、すべて埋まっていれば成功メッセージが表示されます。先生・クラス・教室・科目タブ
   では、週の埋まり具合をミニ一覧で確認できます。タイルをクリックすると時間割作成画面のその対象の詳細画面が
   開きます。「一括表」タブには「AIで自動駒入れ」ボタンも直接あり、この画面を見ながら実行すると、コマが少しずつ
   埋まっていく様子が視覚的に確認できます（実行完了後は自動的にこの一括表画面へ切り替わり、結果を確認できます）。
7. **集計**: 現在配置されている週コマ数を先生・クラス・科目ごとに集計し、年間の週数を掛けた年間換算値を確認できます
   （年間実績集計プログラムの簡易版）。CSV出力も可能です。
8. **会議設定**: 職員会議など特定の曜日・時限に先生（・教室）を拘束する予定を登録すると、駒入れの際に自動的に
   その時間へ授業が配置されないよう避けます。
9. **試験時間割**: クラスごとに出題科目を選択して、通常の時間割とは別の試験期間用グリッドへ自動作成・手動編集
   できます。
10. **帯時間割**: 中学校向けのスライド時間割。週より長い基本枠（帯）を自動作成し、週へスライドさせて実際の
    時間割として確認できます。帯の作成中は曜日固有の個別条件や1日あたりの上限は適用されない簡易版です。

特別支援学級は、クラスに「特別支援学級」チェックと交流学級を設定すると、授業設定画面から交流学級との
合同授業をワンクリックで登録できます。

右上のツールバーから、JSON形式でのファイル保存/読み込み、他の担当者が作成したJSONデータとの統合（統合連結）、
CSV出力、HTML出力（アプリなしで閲覧できる読み取り専用ビューワー）、印刷（用紙サイズ・向き・現在の表示のみ/
全クラス一括の指定可）、自動バックアップ（ブラウザ内に最大10世代を保存し、いつでも復元可能）ができます。
右サイドバーの「AIアシスタント」からは、未配置授業の原因や調整方法について相談できます。

## Excelから読み込む（統合版簡単設定）

ヘッダーのアップロードアイコン（Excelから読み込む）から、「クラス定義」「普通」「TT」「選択授業」「総合」
「先生名称」シートを含む統合版簡単設定エクセルブック（.xlsx / .xlsm）を読み込み、クラス・先生・科目・授業を
一括で自動生成できます。時数は半角数字（例：4）または「2②」「6②」のような全角丸数字付きの連続授業表記に
対応しています。

以下は現在の簡易化事項です。
- この形式には教室の情報が含まれないため、取り込んだ授業には教室が設定されません。必要に応じて授業設定画面
  から追加してください。
- 複数科目にまたがる展開授業（例：技術・家庭を2人の先生が同時に別科目として教える形式）は、科目ごとに別々の
  コマとして取り込まれます。総コマ数・担当・クラスは保持されますが、「同時進行」という前提は失われるため、
  必要に応じて授業設定画面で内容をご確認ください。
- 3時間以上の連続授業（③など）はこのアプリでは非対応のため、2時間連続として取り込まれます。

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY`（Cloudflare環境では `API_KEY`）を設定
3. Run the app:
   `npm run dev`

## GitHub Pages への自動デプロイ

`main` ブランチに push すると `.github/workflows/deploy-pages.yml` が `npm run build` を実行し、
`dist/` を GitHub Pages に自動公開します。リポジトリの Settings → Pages で
「Source: GitHub Actions」を選択しておいてください。公開URLは
`https://<ユーザー名>.github.io/schedule-planning/` になります。

GitHub Pagesは静的ファイルのみのホスティングのため、AIアシスタントのチャット機能（`/api/chat` を呼び出す
Cloudflare Worker）は動作しません。それ以外の時間割作成・編集・出力機能はすべて問題なく動作します。
チャット機能まで含めて公開したい場合は、`wrangler.json` を使ったCloudflare Workersへのデプロイをご利用ください。
